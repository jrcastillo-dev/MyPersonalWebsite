## About the Project
The webpage contains my personal information, profile picture, program and year level, short biography, skills, and contact information. 
It also includes JavaScript interactivity.

## Features
* Personal profile
* Profile picture
* Student information
* Short biography
* Skills section
* Contact information
* Responsive design
* Hover effects
* Mobile-friendly layout

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure
```text
LastName_PersonalProfile/
├── index.html
├── style.css
└── script.js
```

## Responsive Design
The webpage is designed to work on:
* Desktop
* Tablet
* Mobile devices

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
You can also use **Visual Studio Code with Live Server** to view the webpage.
